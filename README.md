# My App (MERN Monorepo)

This repository contains the full-stack application — user client, admin panel, and backend API.

## Structure
- `/client` — React app for users
- `/admin` — React app for admin dashboard
- `/server` — Node.js/Express backend API

## Commands
To run each part:

```bash
# Client
cd cloudix
npm install
npm run dev

# Admin
cd admin
npm install
npm run dev

# Backend
cd backend
npm install
npm run dev
